# Build one approved plan

Open the plan in Plans, then copy the prompt from its Build tab.
That prompt contains the exact plan, approval, and revision IDs.
Build applies to one plan. A Deliverable is not a build target.

If there is no approved revision, stop. Do not create, revise, or implement a plan.
Use the named approval to start the internal implementation run with your actual session ID.
Read every page of the pinned agreement before implementation.
Read each truncated revision in full.
Follow the approved scope, approval conditions, acceptance criteria, and required tests.

If you need to depart from the approved plan, stop affected work and use `requestDeviation`.
The request goes to Inbox with options to approve, request revision, or decline.
Wait for the person's sent answer and feedback.
The sent answer records a Decision.
Read the updated agreement before continuing affected work.
